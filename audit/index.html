1. System Stock / Current Inventory Import

CSV or Excel · designed for 20,000+ current rows

Import the client's current stock before physical counting. Use one System Qty column. It accepts decimal quantities such as 2.5 and pharmacy-style quantities such as 2Strip10Tab; Pack Size is used when loose units need conversion. The portal matches item code + batch, barcode + batch, then item name + batch. Purchase Rate is treated as Ex-GST cost. GST % is stored separately for reference and optional future GST-inclusive reporting.

2. Physical Quantity Import

Match physical counts against system stock

Upload physical stock prepared in Excel/CSV. Use one Physical Qty column. It accepts decimal quantities such as 2.5 and pharmacy-style quantities such as 2Strip10Tab. When loose units are included, Pack Size is used to convert them to decimal pack quantity automatically. If an item/batch does not exist in current stock, it is flagged as Unlisted Excess.

Admin Audit Operations

Routine audit controls — no Supabase access required

Use these controls for normal audit administration. They do not delete Current/System Stock unless you use the separate Imported Data Management section below.

Stock Allocations Remove all medicine-to-team/zone allocations for the selected audit. Current Stock and physical counts stay intact.
Audit Lifecycle Close/archive a completed audit or reopen a closed audit for further work.
Recent Count Cleanup Delete one incorrect/test count directly from Recent Count Activity using its Delete button. Current Stock and allocations remain.

Imported Data Management

Applies only to the currently selected audit project

Use these controls only when a wrong file was imported or while resetting test data. Client, audit project, zones and teams are not deleted.

Physical Count Data Deletes physical count rows, recounts and physical-import history. Current/System Stock is retained.
Current/System Stock Data Deletes imported current-stock master and its import history. Physical counts must be deleted first.
Reset Audit Imported Data Deletes both Current/System Stock and Physical Count data for this audit while keeping the audit project, zones and teams.
